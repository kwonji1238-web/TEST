# 클래스로(Classro) 회사 소개 웹사이트

동네 공방·작업실의 원데이 클래스를 앱에서 찾고 바로 예약·결제하는 서비스 **클래스로**의 소개 페이지입니다.
`00_회사소개.md` 내용을 기준으로 만들었습니다.

> 수업용 가상 회사입니다. 등장하는 회사·인물·수치는 모두 지어낸 것입니다.

## 폴더 구조

```
TEST/
├─ index.html        # 메인 페이지
├─ css/
│  └─ style.css      # 스타일
├─ js/
│  └─ main.js        # 인터랙션
├─ 00_회사소개.md      # 원본 기준 문서
└─ README.md
```

## 실행 방법

별도 설치나 빌드 없이 `index.html`을 브라우저로 열면 됩니다.

## 페이지 구성

1. 메인(Hero) — 서비스 소개와 클래스 종류
2. 핵심 수치 — 제휴 공방, 월 예약, 평균 결제액, 직원 수
3. 한 줄 소개
4. 기본 정보
5. 핵심 사용자 흐름
6. 이번 분기(2026년 4분기) 목표
7. 최근 있었던 일
8. 팀별 고민
9. 키트 파일

## 기능

- 모바일 대응(반응형) 및 햄버거 메뉴
- 스크롤 시 섹션 등장 효과
- 핵심 수치 카운트업 애니메이션
- 현재 섹션에 따른 메뉴 강조
- 예약 전환율 진행바(2.7% → 목표 3.9%)

## 수정 방법

- 내용: `index.html`
- 색상: `css/style.css` 상단 `:root` 변수(`--brand` 등)
- 동작: `js/main.js`
